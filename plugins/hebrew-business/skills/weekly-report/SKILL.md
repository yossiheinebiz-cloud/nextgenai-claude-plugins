# Weekly report from a spreadsheet

## Steps
1. Read the file. List the columns you found and the date range. If dates are ambiguous (day/month), ask once; Israel uses DD/MM.
2. Clean: drop empty rows, note duplicates and obvious errors. Report what you removed.
3. Compute with code, not by eye: totals this week vs last week, change in %, top 5 items, anything above or below normal.
4. Write the report in Hebrew:
   - שורה תחתונה: one sentence with the main change.
   - 3 to 5 numbers that matter, each with last week next to it.
   - מה בולט: 2 to 3 findings, each tied to a number.
   - מה לעשות השבוע: 2 to 3 concrete actions.
   - הערות על הנתונים: missing data, assumptions.
5. If a chart helps, make one simple chart (bar or line), labeled in Hebrew.

## Rules
- Every number in the text must come from your calculation. Show the formula or code if asked.
- Do not guess causes. Write "ייתכן ש" and say what would confirm it.
- No em or en dash. Numbers LTR inside Hebrew.
